Security boundaries
-------------------
- Tailscale Funnel is not called by PlayZone v0.31.
- Port 8000 is not opened by the installer firewall rules.
- Voltra TCP 10086 keeps its existing Private-network firewall rule.
- Tailscale Auth Key handling from v0.30 remains temporary/non-persistent.
- ROOT password is never passed in a process command-line argument by the installer.

Windows-specific validation boundary
------------------------------------
This build environment is not Windows, so the edited PowerShell installer and the real
Tailscale Windows service/Serve flow could not be executed end-to-end here. The original
v0.30 package already contained the Windows Service/offline runtime structure; v0.31 keeps
that structure and changes the ROOT/Tailscale setup logic. Before a customer rollout,
perform one clean install and one v0.30 -> v0.31 upgrade on a Windows test PC, then verify:
1) Windows Service starts after reboot.
2) ROOT login requires the configured password.
3) Local UI opens only on 127.0.0.1:8000.
4) Tailscale Serve shows the expected https://...ts.net URL.
5) The URL is reachable from an authorized support device and not from an unauthorized one.
6) Disable Remote Access removes the Serve endpoint while local PlayZone continues running.
