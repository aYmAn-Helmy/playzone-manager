PlayZone Manager v0.33
=======================

- إضافة Desktop Application باستخدام Electron/Chromium بدل الاعتماد على Microsoft Edge أو Chrome.
- تشغيل الواجهة محلياً على http://127.0.0.1:8000 مع منع DevTools والتنقل الخارجي داخل تطبيق الكاشير.
- إضافة Responsive UI للموبايل والتابلت والديسكتوب.
- Sidebar على الموبايل والتابلت يعمل كـ Drawer باللمس، وعلى الديسكتوب يعمل Auto-hide.
- كروت الأجهزة تتحول تلقائياً إلى عمود واحد على الموبايل وعمودين على التابلت.
- الجداول تتحول إلى Cards مقروءة على الشاشات الصغيرة.
- النوافذ المنبثقة تصبح Bottom Sheets مناسبة للمس.
- نقل System Logs إلى صفحة منفصلة ROOT-only.
- تثبيت كروت آخر الفواتير وحالة النظام أعلى الأجهزة مع Scroll داخلي.
- إضافة Offline Python runtime كامل وموثق للتحزيم المحلي.
- الإبقاء على اسم وهوية PlayZone Manager الأصلية.
- لا توجد صفحة مشاريب ولا APIs خاصة بالمشاريب في هذه النسخة.
